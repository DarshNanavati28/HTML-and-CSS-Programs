## 💻 How to Run

You don't need any special software to run these programs.

### Method 1 — Open Directly

1. Download or clone this repository.
2. Navigate to the required `.html` file.
3. Double-click the file.
4. It will open in your web browser.

### Method 2 — Using VS Code

1. Open the repository in **Visual Studio Code**.
2. Open the required HTML file.
3. Open it using your browser.

You can also use the **Live Server** extension for easier development and automatic page refreshing.
